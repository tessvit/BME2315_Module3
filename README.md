Description of the Repository: This repository contains Module3_Project_JupyterNotebook compiles code and explanations to suggest an alternative GLP1 to Wegovy and Ozempic called Cavalitide. In this Jupyter Notebook, we calculated Kd2 using both the brute force and curve fit methods to fit a receptor binding model for Cavalitide. We also simulated the pharmacokinetics of the treatment by the solve_ivp function in Python to show the depot amount and free semaglutide in blood of Ozempic and Wegovy in comparison to Cavalitide. Lastly, we simulated a combined pharmacokinetics-pharmacodynamics model that predicts GLP1 receptor activity during treatment, fine tuning the dosage to reach 90% active receptors.
This project was a great way to learn about what goes into drug development, and we hope these methods can be used in the future to further explore new possible GLP1s.
